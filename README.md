# Rua

> [!NOTE]
> This project is a work in progress.

Rua is a Lua compiler written entirely in Lua, with no external dependencies.

Its goal is to compile Lua source code into C. Currently, Rua supports parsing and intermediate representation (IR) generation. C code generation is still under development.
